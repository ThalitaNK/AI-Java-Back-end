# Recursos e Materiais

## Semana 1
- **Módulos do Bootcamp:** Cursos iniciais de IA e fundamentos da linguagem.
- **O seu Contexto:** Os módulos "Introdução à Plataforma Java", "Ambiente de Desenvolvimento Java" e "Aprendendo a Sintaxe Java" (da DIO) já fazem parte do seu currículo. Use para aquecimento.
- **Na prática:** Aproveite sua vivência com Microsoft Azure e Visual Studio para deixar o ambiente Java rodando liso no novo setup.

## Semana 2
- **Módulos do Bootcamp:** Orientação a Objetos e Imersão em Collections.
- **O seu Contexto:** Faça um paralelo direto com "C#: ORIENTAÇÃO A OBJETOS" e "C#: usando herança e implementando interfaces" da Alura. A essência arquitetural não muda; traduza o que já sabe no C# para o Java.

## Semana 3
- **Módulos do Bootcamp:** Clean Code, SOLID e conectividade com Banco de Dados.
- **O seu Contexto:** No JDBC, lembre-se de conectar a API ao SQL Server via Docker (projeto Monitor de Hardware). A missão é criar o "Guardião" dos dados. Sua vivência como Software Engineer Junior ajudará a entender Clean Code na resolução de débitos técnicos.

## Semana 4
- **Módulos do Bootcamp:** Reta final com Spring, OpenFeign e o desafio da API com reconhecimento de fala.
- **O seu Contexto:** Traga a experiência de back-end e Git/Github. O Spring Boot vai automatizar configurações complexas e permitir o foco nas regras de negócio.
