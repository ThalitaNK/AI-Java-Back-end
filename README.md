# Plano de Estudos: AI Java Back-end (Bootcamp Santander 2026)

**Objetivo:** Finalizar o Santander Bootcamp 2026 em 30 dias, criando uma base prática e sólida no ecossistema Java. A meta é conectar a bagagem lógica que já possui com ferramentas de Inteligência Artificial e Spring Boot, construindo projetos robustos para alavancar a transição de carreira.

## Tópicos Iniciais
- Sintaxe Java
- Orientação a Objetos
- Collections
- Clean Code/SOLID
- Banco de Dados (JDBC)
- Spring Boot

## Estratégia de Produtividade
A regra de ouro para este mês é o esquema **"2+2"**: 
- **2 horas** devorando a teoria na plataforma
- **2 horas** na IDE, quebrando a cabeça e sujando as mãos no código.
